Recipe Card

A responsive Recipe Card Web Page developed using HTML5 and CSS3 as part of my Web Development Internship Day 10 Task.

Project Description

This project presents a single recipe card for Chocolate Pancakes. It includes a recipe image, ingredients list, preparation steps, cooking information, and a responsive layout that works on desktop and mobile devices.

How to Run
Create a folder named Recipe-Card.
Add index.html and style.css.
Keep both files in the same folder.
Open index.html in any web browser.
The recipe card will be displayed.
Responsive Design

The webpage is designed to work on:

Desktop
Laptop
Tablet
Mobile devices

Media queries automatically adjust the image size, content spacing, heading sizes, and recipe information layout for smaller screens.
